# Learning & Optimization

## Level 1: One-Sentence Summary
Learning is the process of iteratively adjusting parameters to minimize a loss function using gradient-based optimization algorithms.

## Level 2: Intuition
If the architecture is the "body" of a neural network, optimization is the "heart." It defines how the network improves. We use **Loss Functions** to measure how far we are from the truth, and **Gradient Descent** to figure out which way to "step" to reduce that error. **Backpropagation** is the efficient tool that calculates these steps for every single part of the network.

### Core Optimization Nodes:
- [Gradient Descent](Gradient_Descent.md): The navigator of the error surface.
- [Backpropagation](Backpropagation.md): The chain-rule messenger.
- [Loss Functions](../concepts/Loss_Functions.md): The metric of success.

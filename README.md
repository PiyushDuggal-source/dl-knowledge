# Deep Learning Knowledge Brain

An LLM-maintained personal knowledge base for Deep Learning, built using the `gbrain` architecture and served via Quartz.

## 🧠 For LLM Agents
This repository is optimized for autonomous crawling and context retrieval.
- **Entry Point:** [index.md](https://piyushduggal.github.io/dl-knowledge/index.md)
- **Manifest:** [manifest.txt](https://piyushduggal.github.io/dl-knowledge/manifest.txt)
- **Schema:** [schema.md](https://piyushduggal.github.io/dl-knowledge/schema.md)

## 🌐 For Humans
Visit the interactive Wikipedia-style site at:
**[https://piyushduggal.github.io/dl-knowledge/](https://piyushduggal.github.io/dl-knowledge/)**

## 🛠 Features
- **High-Fidelity Math:** Native LaTeX rendering + original slide formula images.
- **Compiled Truth:** Synthesized summaries cross-referenced from lecture slides and transcripts.
- **Evidence Trail:** Append-only timeline for every concept node.
- **Graph View:** Interactive visualization of Deep Learning concepts.
- **Standard Links:** Uses standard Markdown links for maximum agent navigability.
